KALPANA RESTAURANT WEBSITE CONCEPT
=================================

Files:
- index.html — complete responsive single-page website.

How to use:
1. Open index.html in Chrome/Edge/Safari.
2. The page uses Google Fonts and image URLs, so an internet connection is recommended for the full visual experience.
3. Before selling/launching, replace the demo food images with photos supplied/approved by the restaurant.
4. Confirm the menu, phone number, opening hours, address and any ordering/reservation links with the owner.
